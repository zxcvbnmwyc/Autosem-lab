DATA BOUNDARIES

你的图片，
清楚地知道去了哪里。

AutoSEM 把“语义定位”和“像素级分割”分开处理。我们希望你能在每次操作前，准确知道哪些数据留在本机，哪些会发送到你主动配置的模型服务。

01

本地处理

上传图片、手动点选和框选、SAM2 分割，以及导出的 mask 和轮廓文件，均由运行 AutoSEM 的机器处理和保存。仅使用手动提示时，图片不会因分割本身发送到外部视觉模型。

02

云端定位是按需触发的

当你点击“一键剪辑”、“仅自动定位”或“自动定位并生成轮廓”时，当前图片和你填写的文字会发送给你已配置的 Qwen 视觉模型服务。一次剪辑会先让 Qwen 规划本地效果，再定位主体；最终 mask、合成和导出仍在运行 AutoSEM 的机器上完成。不会在未点击此类操作时自动发送。

请注意云端模型服务对数据的处理方式由该服务及你的账号配置决定。处理敏感图片前，请先确认其服务条款与权限设置。
03

结果文件与保留

为了让你下载结果，系统会在本地任务目录中保存上传图片和生成文件。部署到云服务器后，这些文件将保存在该服务器对应的存储空间；正式对外开放前，应根据你的产品需要设置访问控制与清理策略。

04

密钥与配置

视觉模型服务的 API Key 仅应保存在后端环境变量或服务器密钥管理系统中。工作台不会把 API Key 传到浏览器，也不应将它写入前端代码、截图或公开仓库。
