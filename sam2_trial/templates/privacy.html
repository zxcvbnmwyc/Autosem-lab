DATA BOUNDARIES

你的图片，
清楚地知道去了哪里。

AutoSEM 的图片处理不在浏览器里完成：上传后的图片会暂存在运行 AutoSEM 的服务器。只有你主动使用智能功能时，图片和文字才会额外发送到已配置的视觉模型服务。

01

AutoSEM 服务器内处理

上传图片、手动点选和框选、选区生成、图片合成和结果导出，均在运行 AutoSEM 的服务器内处理。仅使用手动提示时，图片不会因选区生成而发送到额外的云端视觉模型。

02

云端定位是按需触发的

当你点击“一键剪辑”、“查看 AI 推荐位置”或“智能选区（可确认）”时，当前图片和输入文字会发送给已配置的 Qwen 视觉模型服务，用于理解需求和定位主体。该模型不会直接生成、替换或改写图片；最终选区、合成和导出仍由 AutoSEM 服务器完成。未点击这些功能时，系统不会自动发送图片。

请注意云端模型服务对数据的处理方式由该服务及你的账号配置决定。处理敏感图片前，请先确认其服务条款与权限设置。
03

结果文件与保留

为了让你下载结果，系统会在服务器任务目录中保存上传图片和生成文件。当前默认保留 72 小时，过期后自动清理；同一任务的下载链接仅对创建该任务的浏览器会话有效。请不要分享包含敏感图片的下载链接。

04

密钥与配置

视觉模型服务的 API Key 仅保存在服务器环境变量或密钥管理系统中，不会出现在网页、下载文件或公开仓库。请勿把 API Key 写入前端代码、截图或公开内容。
